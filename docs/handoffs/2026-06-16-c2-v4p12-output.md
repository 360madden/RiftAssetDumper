## Binding Decision 1: Transform Truth Model

**Decision**: ACCEPT mesh-parent-chain accumulation as documented in `coordinate-contract.md`.

- Start from each mesh's `ParentNiNodeIndex` in `world.json`
- Walk up through the NiNode parent chain to root
- Accumulate root-to-leaf: `v_world = R * (S * v_local) + T`
- Scene-manifest carries `world_transform_summary` (aggregate) + `world_json` reference (full detail)
- Multi-mesh assets retain per-mesh detail via `world_json` sidecar

**Evidence**: 4 non-id assets with non-identity transforms on mesh parent chain; 217/217 flythrough scale = 1.0; `build_world_placed_merge.py` accumulator verified.

## Binding Decision 3: Scene-Manifest v1 Schema

**Decision**: LOCK the draft schema with 3 additions + 1 gate revision.

### Schema field set (locked)

| Block | Fields | Change from draft |
|---|---|---|
| `geometry` | `obj_path`, `mesh_block`, `mesh_size`, `vertex_count`, `face_count`, `has_faces`, `render_class`, **`obj_sha1`** | ADDED `obj_sha1` (optional, `^[0-9a-f]{40}$`) |
| `world` | `world_json`, `node_count`, `mesh_count`, `transform_semantics`, `coordinate_system`, `world_transform_summary`, `world_transform_identity` | No change |
| `materials` | `material_status`, `texture_property_count`, `material_property_count`, `vertex_color_property_count`, **`scanned_at`**, `notes` | ADDED `scanned_at` (optional, `date-time`) |
| `textures` | **`source`**, `linked_texture_count`, `linked_textures`, `missing_texture_count`, `placeholder_texture_count` | ADDED `source` (REQUIRED, enum: `scene`/`flythrough`/`unknown`) |
| `provenance` | `cohort`, `source_nif_hash`, `flythrough_index_entry`, `evidence_files` | No change |
| `validation` | `schema_valid`, `consumer_ready`, `warnings`, `errors` | No schema change; producer gate revised |

### Schema gap resolutions

| # | Gap | Decision | Rationale |
|---|-----|----------|-----------|
| M3 | **`textures.source` enum** | **ACCEPT** — added as required field | Highest priority. 23/24 cohort contradictions resolved by discriminating flythrough vs scene texture sources. Without this, consumers cannot route textures correctly. |
| #6 | Geometry permissiveness | ACCEPT schema minima, REVISE producer gate | Schema allows `vertex_count=0`/`face_count=0` (valid for pre-extraction manifests). Producer-level `consumer_ready` gate requires `>0` values. |
| #7 | `Materials.scanned_at` | ACCEPT — added as optional | Distinguishes "scanned, found zero" from "never scanned". |
| #8 | `geometry.obj_sha1` | ACCEPT — added as optional | Cross-schema parity with `asset-mesh-manifest-v1`. |
| #9 | Accumulated vs declared transform | **DEFER** to C2-V4P3 | Current single `world_transform_summary` adequate for v1. Splitting adds complexity without demonstrated consumer need. |

## consumer_ready gate (producer-level)

The `build_validation` function now gates `consumer_ready=true` on:

```
vertex_count > 0
AND face_count > 0
AND material_status != "unknown"
AND textures.source != "unknown"
AND linked_texture_count > 0
AND mesh_block is not None
```

All 24 cohort manifests currently report `consumer_ready=false` — geometry extraction, material scanning, and mesh_block mapping are pending (C2-5.x).
