## Design decisions

1. **Subprocess orchestration (not direct function calls).** Mirrors `bulk_export_for_flythrough.py` (FT-2) pattern. Reasons: the existing single-zone scripts own their CLI / JVM bring-up; duplicating that doubles maintenance surface; per-zone subprocess spawns give clean fail-isolation (one bad zone never halts the batch).
2. **Eligible-zone filter.** Conservative: zones pass only when ≥5 walkable assets (walkability-classification ∩ flythrough-index.zone.tuple). Excludes zones without enough geometry + walkability data to produce a meaningful navmesh.
3. **`__all__` re-export pattern.** `scripts.build_all_navmeshes` declares `__all__ = [..., "subprocess", ...]` so tests can `monkeypatch.setattr(bam.subprocess, "run", fake_run)` (re-export not subject to mypy `attr-defined`). Standard Python idiom.
4. **Lazy-default paths.** `load_flythrough_index` and `load_walkability` use `path: Path | None = None` with module-level constant resolution at call time, dodging Python's default-arg binding trap (a `Path` default would be captured at def-time).
5. **Status-cheap self-check.** `_validate_against_schema` runs lightweight gates (schema_version const, enum pins, sibling-reference, regex, bounds inversion, walkable_labels ordering) without a runtime `jsonschema` dep. Future drift handling: load the regex from the on-disk schema file once at module import (deferred followup; ~5 lines).
6. **`connected_zones` field pre-wired.** Empty array `[]` on every per-zone entry today, schema-locked as `^[a-z0-9_]+(\.[a-z0-9_]+)+$` item pattern. M6.2 fills with adjacency; M6.3 consumes for cross-zone routing.

## How to ship the M6.2 adjacency graph

Once M6.1 is merged, M6.2's deliverable is:

```python
# scripts/build_zone_connection_graph.py (M6.2 sketch)
def compute_adjacency(navmesh_index_path: Path) -> dict[str, list[str]]:
    """For each pair of zones, compute boundary-poly overlap or known
    connection points. Returns {zone_tuple: [adjacent_zone_tuples]}.
    """
    idx = json.loads(navmesh_index_path.read_text())
    adjacency = {}
    for zt, entry in idx["zones"].items():
        if entry["status"] != "built" or not entry.get("bounds"):
            adjacency[zt] = []
            continue
        adjacency[zt] = [
            other_zt for other_zt, other_entry in idx["zones"].items()
            if other_zt != zt
            and other_entry.get("status") == "built"
            and other_entry.get("bounds")
            and _boundary_overlaps(entry["bounds"], other_entry["bounds"])
        ]
    return adjacency

```

Then update `navmesh-index.json` in-place:

```python
for zt, neighbors in adjacency.items():
    idx["zones"][zt]["connected_zones"] = sorted(neighbors)

```
