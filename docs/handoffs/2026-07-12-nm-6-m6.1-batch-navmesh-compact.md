## Key design (load-bearing only)

- **Subprocess orchestration** (not direct import) — mirrors FT-2 pattern; per-zone fail-isolation.
- **Eligible-zone filter** — `walkability.label ∩ flythrough-index.zone.tuple`, ≥5 walkable assets.
- **`__all__` re-export** — `subprocess` declared so `monkeypatch.setattr(bam.subprocess, "run", ...)` works.
- **Lazy-default paths** — `path: Path | None = None` + module-level resolution dodges Python's def-time capture trap.
