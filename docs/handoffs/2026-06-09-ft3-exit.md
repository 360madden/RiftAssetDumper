## Key design decisions

1. **Integrated emitter, not standalone script**: The FT-3 plan suggested creating `scripts/emit_mesh_manifest.py` as a separate script, but the bulk exporter already writes per-OBJ sidecars. We upgraded the existing `_write_obj_sidecar()` function to emit the FT-3 schema instead of creating a new script. This keeps the pipeline self-contained.

2. **`_parse_obj_stats()`**: Extracts vertex/face counts from OBJ files in a single pass. Correctly handles `v` and `f` lines while excluding normals (`vn`) and textures (`vt`).

3. **`export_mode` tracked as state**: Initialized to `"export-obj"`, set to `"experimental"` only when the two-pass fallback triggers. No fragile text-heuristic.

4. **Probe lookup enrichment**: When `--use-probe-lookup` is set, the full probe lookup data is passed to the sidecar emitter, populating `mesh_size`, `probe_note`, and other fields.

5. **Schema follows project conventions**: Uses `$schema: "https://json-schema.org/draft/2020-12/schema"`, `additionalProperties: false`, and consistent naming with existing schemas.
