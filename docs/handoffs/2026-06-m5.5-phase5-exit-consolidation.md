## Part 2: M5.2 — Descriptor-Guided Pairing Confidence Adjustment

**Location**: `AdjustConfidenceByDescriptor()` + `FindNifMeshProbePairings` (Program.cs)
**Type**: Active behavioral consumption (first confidence-affecting descriptor use)

### What was built

- `AdjustConfidenceByDescriptor(int confidence, string? vertexDescriptor, string? vertexRole)` — adjusts pairing confidence by descriptor
  - +5 boost when float-family descriptor matches float role (position/normal/uv)
  - -10 dampen when u16-family descriptor on float role
  - Capped at 100, floored at 0
- Called in `FindNifMeshProbePairings` after `compatibleVertexCount` boost, before pairing construction

### Refactoring

- Extracted shared helpers: `IsFloatRole()`, `IsFloatDescriptor()`, `IsU16Descriptor()`
- Used by `CheckDescriptorRoleConsistency`, `AdjustConfidenceByDescriptor`, and M5.3 boost logic
- Eliminated ~12 lines of duplicated classification logic

### Verification

- 10 new tests (39/39 pass): float match boost, u16 mismatch dampen, cap/floor, null/unknown guards, index role no-change
