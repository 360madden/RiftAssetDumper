### Gate 3: descriptor-table-sample-proof

| Field | Value |
|---|---|
| **Current state** | candidate |
| **Blocks promotion** | ✅ yes |
| **Phase 2 evidence** | Transformative — base-model review found all static bytes zero; per-block-embedded finding challenges the gate's premise |
| **Key positive finding** | The static "descriptor table" at Ghidra addresses is all-zero because NO static table exists — descriptors are embedded per-block |
| **Key negative finding** | Gate premise is falsified; the gate as currently defined cannot be "passed" because it tests a wrong model |
| **Assessment** | **candidate (reclassified)** — gate needs redefinition, not pass/fail determination |
| **What would clear it** | Gate redefinition to test per-block descriptor consistency across a scaled sample corpus, OR gate removal if per-block-embedded model is accepted as the truth |
| **Can advance?** | **No** — gate is measuring the wrong thing (static table) |

**Reclassification rationale**:
1. M2.1 base-model review: "All static bytes zero: true" at Ghidra's candidate stride-12 table addresses
2. M2.1 ShiftedSamples: 184 blocks each have 4 descriptor bytes at offset 24 — these are per-block embedded, not table entries
3. M2.1 descriptor-sample-compare: 10 blocking items, but the "table sample" concept is what creates many of these blockers
4. **Conclusion**: The descriptor is NOT a static table. The "table-sample" gate tests a Ghidra artifact, not the actual data structure.
