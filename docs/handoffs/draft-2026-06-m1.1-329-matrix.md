## Key Pattern Observations

**Synthesis from the full M1.1 curated sample** (candidate-only; 12 paired + 1 one-sided; confirmed by final Matrix Synthesizer run post-ingestion enhancement; references Block 34 Prober + main-line probes + ID Curator queue):

The expanded sample (now 12/12 paired) continues to show — and strongly quantifies — the repeatable structural split first noted in the role-analysis parent handoff:

- **mesh#7 variants** (across the full range 77v down to 22v payloads in the 12 pairs): `AttributeSets = 1`. Recognized complete attribute set using the family-shared primary position source at @212 (position-float3-ror1-lead c=75 in all cases), plus normal at @220 (normal-float3-ror1-lead c=85) and UV at @304 (uv-float2-ror1-lead c=80). Consistent extra u32-repeated-pattern body at @296 (c=25). Vertex counts match vector counts on the attribute set. AttrExtraStreamCount=1.

- **mesh#34 variants** (all 12 in scope, 12 paired): `AttributeSets = 0`. Re-uses the identical primary position reference (@212/#28, same payload/role: position-float3-ror1-lead c=75). The corresponding @304 stream is scored as an *additional position-float3-ror1-lead* stream (c=75, not UV) in all 12 paired cases. Normal stream on varying block (often #53, sometimes treated as UV on lower-v cases). Same @296 u32 pattern body present. VertexCount=0 on the mesh entry (consistent with attrSets=0). AttrExtraStreamCount=0.
